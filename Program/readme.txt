FlowDesk M2 账号与项目  v0.2.0

全新使用：
1. 解压完整文件夹。
2. 双击 FlowDesk.exe。
3. 注册账号，然后开始管理自己的项目。

已有 M1 项目：
1. 关闭旧版启动窗口，复制一份原来的 data 文件夹备份。
2. 用新版 FlowDesk.exe 替换旧文件夹中的 EXE，保留 data。
3. 启动后注册第一个账号，并确认接收页面显示的旧项目。

升级前程序会自动备份旧数据库。请勿同时运行旧版和新版。
运行无需安装环境、无需联网。账号仅属于当前本地项目库。
本版不提供找回密码，请保存好自己的密码。
