# FlowDesk M2 账号与项目

这是在 M1 Project 基础上继续开发的版本。新增注册、登录、退出、保持登录状态和当前账号查看，并让每个项目属于一个用户。原来的项目增删改查、搜索、筛选、排序、导出和备份继续可用。

## 新用户开始使用

1. 先解压完整程序包。
2. 双击 `FlowDesk.exe`，等浏览器自动打开。
3. 首次进入时填写用户名称、邮箱、密码和确认密码，点击“创建账号并进入工作台”。
4. 点击“新建项目”，之后创建的项目都归属到当前账号。

无需安装 Python、Node.js 或数据库，运行无需联网。请使用较新的 Edge 或 Chrome。没有预设账号、默认密码或测试项目。

邮箱在本版中用作登录名，不会发送验证邮件；账号只存在当前电脑上的这个 FlowDesk 项目库中，不是云端账号。

## 从 M1 升级并保留项目

**最简单的方法是只替换旧文件夹中的 EXE。**

1. 关闭所有旧版 FlowDesk 启动窗口。先复制一份旧版的 `data` 文件夹作备份。
2. 将新版 `FlowDesk.exe` 复制到你原来运行程序的文件夹，替换旧 EXE。保留原来的 `data` 文件夹。
3. 双击新版 EXE。它会先自动备份旧数据库，再升级结构。
4. 注册你的第一个账号。页面会显示检测到的旧项目数量；勾选“我确认将这些旧项目归属到此账号”，再提交注册。
5. 注册成功后，旧项目会出现在你的列表中，名称、描述、状态、日期和编号都会保留。

自动备份位于 `data/backups/flowdesk-before-M2-日期时间.db`。备份失败时，程序会停止升级，不会继续修改旧数据库。

如果你希望在一个新文件夹运行 M2，可以在第一次打开新版之前，把旧版整个 `data` 文件夹复制到新版 EXE 旁边。不要同时运行指向同一份数据库的旧版和新版，也不要使用 M1 打开已经升级的数据库。

旧项目仅由首次注册的账号接收。之后注册的账号有各自空白的项目空间，不能接收、浏览或修改其他账号的项目。请由旧项目实际使用者完成首次注册。

本次交付没有改动你另存的旧版程序或实际项目库；迁移会在你用新版打开旧数据库时执行。

## 登录与退出

- 用注册时的邮箱和密码登录；邮箱不区分大小写。
- 用户名称可包含中文，长度为 1–40 个字符。
- 注册密码长度为 10–128 个字符，支持中文和空格，首尾空格会被保留，不能全为空格。
- 勾选“在此浏览器保持登录 30 天”，可在有效期内保持登录，包括重启程序后。使用无痕窗口、清除 Cookie 或更换浏览器后需要重新登录。
- 未勾选时，会话有效期最多 8 小时；浏览器可能恢复会话 Cookie，所以离开共用电脑时请点击“退出登录”。
- 右上角和左下角的账号入口可以查看名称、邮箱及账号编号。
- 点击“退出登录”会注销服务器端当前会话；旧 Cookie 无法继续访问项目。同一浏览器的其他页面也会同步更新。
- 连续输错同一邮箱的密码 5 次后，需要等到该轮首次错误起满 15 分钟再尝试。

**本版尚未提供修改密码、找回密码或邮箱验证，请妥善保存密码。** 新注册另一个账号不会取得原账号的项目。

## 项目与权限

登录后可以创建、查看、编辑、删除自己的项目。五种状态仍是计划中、进行中、已暂停、已完成、已归档。名称必填，截止日期不能早于开始日期。

未登录不能访问项目接口；其他用户的项目即使知道编号也不能读取、修改或删除。列表、数量汇总、搜索和 JSON 导出均只包含当前账号的数据。

注册新账号不会覆盖已有账号。不同浏览器可以分别登录不同账号；同一个浏览器中的多个页面共用一个当前登录账号。

## 数据与备份

```text
FlowDesk-M2/
  FlowDesk.exe
  使用说明.md
  source/                  源码与学习说明
  data/                    首次启动自动创建，升级时保留旧文件夹
    flowdesk.db            账号、项目和会话数据库
    flowdesk.log           运行日志
    backups/               旧版升级前自动备份
```

关闭浏览器不会退出服务；关闭启动窗口会停止服务。每次成功保存都已写入数据库。移动程序时，把 `data` 一起移动；只复制 EXE 会在新位置创建一个空项目库。

**个人项目导出：** 列表右上角“导出项目”保存当前账号的 JSON，不包含密码或其他用户的项目。本版不支持 JSON 导入。

**整个项目库备份：** 启动窗口“备份数据”保存所有账号和项目。它是本机数据库管理员操作，包含全库数据，请妥善保存。备份会移除副本中的登录会话；不会让当前正在使用的账号退出。

**恢复：** 先退出全部 FlowDesk 窗口，并另外保留现有数据库，然后将备份复制到 `data/flowdesk.db`，重新启动并登录。恢复替换整个项目库，不会与现有内容合并。M1 备份恢复后会重新执行升级与首次账号接收流程。

账号隔离作用于应用接口，数据库文件并未加密。拥有电脑文件访问权限的人仍能读取或替换数据库，因此这仍是单机学习与使用版本，不是用于公网部署的团队服务。程序只监听 `127.0.0.1`。

## 常见问题

- **升级后列表是空的：** 确认旧版 `data` 文件夹在新版 EXE 旁边，并确认当前登录的是接收旧项目的账号。
- **页面无法连接：** 保留启动窗口，点击“打开 FlowDesk”重新打开；每次运行的浏览器端口可能不同。
- **提示程序已重启：** 刷新页面后重试。旧页面的请求校验码不会继续生效。
- **提示账号已在其他页面切换：** 刷新后在当前账号下重新操作。
- **无法保存：** 检查所在文件夹能否写入、磁盘空间及 `data/flowdesk.log`。
- **Windows 显示来源提示：** 当前 EXE 尚未进行商业代码签名。

Workspace、成员、Task、评论、附件和 AI 仍按后续阶段开发；当前“我的项目空间”是个人项目视图，不是多人 Workspace。源码和测试说明见 `source/README.md`。
