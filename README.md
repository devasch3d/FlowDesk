# 多机协作工具包（预搭建版）

> 在真实项目代码到位前，先搭好的多机 Git 协作结构。
> 模式：**云端私有仓库（单仓库） + 4 台机器分支分工**。
> 4 台机器：A、B 用 Codex Plus，C、D 用豆包工作版。

## 目录结构

```
collaboration-kit/
├── README.md                    # 本说明（从这一步开始）
├── 01-协作规范.md                # 分支/提交/文件归属/合入/冲突规则（建议放入仓库根目录）
├── 02-任务切分表模板.md          # 模块 → 机器 → 分支 归属表（真实项目到后填写）
├── prompts/
│   ├── 00-边界指令-通用.md       # 所有机器 Agent 的公共硬性边界
│   ├── Codex-Plus-模板.md        # Codex Plus 专用提示词模板（机器 A/B）
│   └── 豆包工作版-模板.md        # 豆包工作版专用提示词模板（机器 C/D）
└── scripts/
    └── setup-machine.ps1        # 每台机器运行一次：克隆 + 建分支 + 同步 main
```

## 快速开始（6 步，约 30 分钟）

### 第 1 步：创建云端私有仓库（你们操作）
- 在 GitHub / GitLab / Gitee 新建**空**私有仓库（不要勾选自动生成 README）。
- 把 4 台机器成员的账号加入仓库成员（或各自添加 SSH 公钥）。
- 记下远程地址（SSH 或 HTTPS），下一步要用。

### 第 2 步：保护 main 分支（平台设置里做一次）
- 将 main 设为保护分支：**禁止直接推送**、要求通过 Pull Request 合入、至少 1 人审查。
- 这是"机器不互联、代码互联"的关键：任何 Agent 都推不进 main，只能走 PR。

### 第 3 步：替换脚本占位符
- 打开 `scripts/setup-machine.ps1`，把顶部 `RepoUrl` 的占位地址换成第 1 步的远程地址。

### 第 4 步（推荐）：先推一个初始提交，让 main 存在
- 在任一机器上克隆后的仓库目录里执行：

```bash
echo "# <项目名>" > README.md
git add -A
git commit -m "chore: 初始化仓库骨架"
git push origin main
```

### 第 5 步：4 台机器各跑一次初始化
- 机器 A：`powershell -ExecutionPolicy Bypass -File setup-machine.ps1 -Machine A`
- 机器 B / C / D 同理（`-Machine B / C / D`）。
- 脚本会自动：克隆仓库 → 创建/切换到 `feat/X` 分支 → 同步 main 最新代码。

### 第 6 步：给 Agent 定边界
- 打开 `02-任务切分表模板.md`，按真实项目把各机器负责的目录填进去。
- 把 `prompts/` 下对应模板复制给每台机器的 Agent（填好占位符）。
- 这样每台机器的 Agent 就只知道改自己的目录，互不越界。

## 占位验证（可选但推荐）
- 完成第 4 步后，其他 3 台机器 `git pull origin main` 能拉到，即说明链路通。
- 更完整的验证：机器 A 改一个文件 → push → 发起 PR → 合入 → 机器 B `git pull` 看到改动。跑通一次，后续就按这个节奏走。

## 流量说明（已确认）

- **只有首次克隆会全量传输**：每台机器第一次 `git clone` 会把仓库当前全部内容下载到本地，这是一次性的；之后不再重复下载已拥有的内容。
- **日常 pull / push 只传增量**：Git 按"差异"传输，纯代码改动通常每次几十 KB ~ 几 MB；4 台机器日常并行消耗很小（每月约几百 MB 量级）。
- **大文件是唯一的大流量来源**：二进制、构建产物、素材等不要提交进仓库（用 `.gitignore`）；必须入库的大文件用 Git LFS，否则每次改动都会全量传输。
- **首月流量估算**（约 50MB 仓库）：首次克隆 4 台约 200MB（一次性）+ 日常约 360MB ≈ 560MB；之后稳定在每月几百 MB。

## 说明与边界
- 本工具包全部为模板：分支名、目录归属、远程地址需按真实情况替换。
- 云端仓库的创建和成员管理需要你们的账号操作；我不索取任何凭证。
- 如果某台机器是 macOS / Linux，告诉我，我再补一份 bash 版初始化脚本。
- 需要把协作规范做成飞书文档、把任务切分表做成飞书表格，也可以随时说。
