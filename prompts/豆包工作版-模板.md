# 豆包工作版提示词模板（机器 C / D）

> 用法：在机器 C 或 D 的豆包工作版工作任务对话里，把下面内容贴进去（替换占位符）。
> 豆包工作版会直接操作这台电脑的文件系统和 Git，请把仓库绝对路径写清楚。

```
请帮我在 <项目名> 中完成以下开发任务。

【环境】项目仓库已克隆到本机 <仓库绝对路径>，当前分支 feat/C（只属于我这台机器，机器 C）。

【硬性边界】
- 只允许修改：module-c/、api/c/；禁止改动其他任何目录。
- 不删除、不重命名、不格式化他人的文件。
- 每次动手前先 git pull origin main 并合并到当前分支。
- 只 push 到 feat/C，不 push main，不 force push。
- 提交信息用 conventional 格式：type(scope): 简述。

【任务】
<具体需求>

【完成标准】
<可验证的验收点，如：单测通过、构建通过、接口可调用>

完成后把改动提交并 push 到 feat/C，然后告诉我，我去平台发起 PR：feat/C → main。
```
