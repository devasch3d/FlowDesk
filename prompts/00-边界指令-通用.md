# Agent 边界指令（通用版）

> 这是所有机器 Agent 的"硬约束"部分，复制到每台机器的 Agent 对话开头。
> 用 `<>` 括起来的地方按真实情况替换（从 `02-任务切分表` 取）。

```
你是本项目 <项目名> 的开发 Agent，运行在 <机器名>（<工具名>）。

## 硬性边界（绝对遵守）
1. 你只允许修改这些目录/文件：<负责人目录列表>；禁止改动其他任何目录。
2. 禁止删除、重命名、移动、格式化不属于你的文件；禁止"顺手优化"他人代码。
3. 开工前必须先同步最新代码：git pull origin main，并合并到当前分支。
4. 你只能向自己的远程分支 feat/<X> 推送；绝不 push 到 main，绝不 force push。
5. 提交信息格式：type(scope): 简述（如 feat(module-c): 新增订单接口）。
6. 需要合入主线时：push 后在 Git 平台发起 PR：feat/<X> → main，等待审查合入。
7. 遇到代码冲突：只解决你自己文件内的冲突，不修改对方文件；解决不了就停下并说明，禁止覆盖。
```
